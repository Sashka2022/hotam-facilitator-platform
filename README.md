# פלטפורמה למנחה · Hotam Facilitator Platform

אפליקציה מלאה (Next.js + Prisma) שמאפשרת למנחה להזין חומרי הדרכה למליאה/מפגש, ומציגה אותם למחנכות כתצוגה מעוצבת: פריסת "מליאה במרכז וחומרים סביבה" בדסקטופ, ורשימת אקורדיון בנייד. לכל חומר יש קישור שיתוף אמיתי וייחודי משלו, שנפתח כעמוד נחיתה מעוצב עם תמונת תצוגה מקדימה אמיתית (Open Graph) — כך שכשמשתפים אותו בוואטסאפ מוצגת תצוגה מקדימה אמיתית, לא מדומה.

נבנתה כהמשך ל[פרוטוטיפ הסטטי](legacy-prototype/) שתוכנן קודם לכן ב-Claude Design, ושומרת על אותה שפת עיצוב (מותג חותם: כחול `#0048FF`, גרדיאנט טורקיז→סגול, פונט Heebo, RTL).

## תכונות

- **תצוגת מחנכות** (`/`) — כרטיס מליאה מרכזי מוקף בכרטיסי חומרים מחוברים בקווים מונפשים (דסקטופ), או רשימת אקורדיון (נייד/מסך צר) — הפריסה מגיבה אוטומטית לרוחב המסך.
- **הוספת חומרים** (`/admin`) — עריכת כותרת/תקציר המליאה, והוספת חומרים (כותרת, כותרת שיתוף אופציונלית, קישור, קטגוריה, תיאור, קובץ מצורף אמיתי).
- **קישורי שיתוף אמיתיים** (`/m/[slug]`) — לכל חומר נוצר קוד ייחודי; העמוד כולל תמונת Open Graph שנוצרת אוטומטית (כך שקישור שנשלח לוואטסאפ/פייסבוק/וכו׳ מציג תצוגה מקדימה אמיתית עם כותרת, קטגוריה ותמונה בצבע המותג).
- **העלאת קבצים אמיתית** — קבצים נשמרים בפועל בתיקיית `public/uploads`.
- **נגישות** — outline נראה במעבר מקלדת (`:focus-visible`), `aria-label`/`role="group"` על אלמנטים מרכזיים, `prefers-reduced-motion` מכבה אנימציות.

## הרצה מקומית

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

האפליקציה תרוץ בכתובת http://localhost:3000.

## משתני סביבה

ראו `.env.example`. `DATABASE_URL` מצביע כברירת מחדל לקובץ SQLite מקומי (`prisma/dev.db`). `NEXT_PUBLIC_SITE_URL` צריך להצביע לכתובת הציבורית של הפריסה (כדי שקישורי השיתוף ותמונות ה-Open Graph ייבנו נכון).

## פריסה לפרודקשן

הפרויקט מוכן לפריסה בכל שירות שתומך ב-Next.js (למשל Vercel). **הערה חשובה:** SQLite מתאים לפיתוח מקומי בלבד. לפריסה אמיתית מומלץ:

1. להחליף את `DATABASE_URL` במסד נתונים מנוהל (Postgres — למשל Vercel Postgres, Supabase או Neon) ולעדכן את `provider` ב-`prisma/schema.prisma` בהתאם.
2. להעביר את אחסון הקבצים המועלים משמירה מקומית (`public/uploads`) לאחסון אובייקטים (S3, Vercel Blob וכד׳), כיוון שסביבות serverless לא שומרות קבצים בין הפעלות.

## מבנה הפרויקט

- `src/app` — עמודי Next.js (App Router) ונקודות ה-API.
- `src/components` — רכיבי React משותפים (Header, MaterialIcon, תצוגת הגלריה, טופס הניהול).
- `prisma/schema.prisma` — מודל הנתונים (מליאה + חומרים).
- `legacy-prototype/` — הפרוטוטיפ הסטטי המקורי (Claude Design), נשמר להשוואה/היסטוריה בלבד — אינו חלק מהאפליקציה הרצה.
