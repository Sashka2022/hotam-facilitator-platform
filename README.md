# פלטפורמה למנחה · Hotam Facilitator Platform

אפליקציה מקומית (Next.js + Prisma) שמאפשרת למנחה להזין חומרי הדרכה למליאה/מפגש בצורה אינטראקטיבית, ולייצא אותם כמסמך PDF מעוצב עם קישורים חיים לשליחה למחנכות (וואטסאפ/מייל). כוללת גם תצוגת גלריה מקוונת (מליאה במרכז וחומרים סביבה בדסקטופ, אקורדיון בנייד) להרצה מקומית או לאירוח עתידי, אם ירצו בכך.

נבנתה כהמשך ל[פרוטוטיפ הסטטי](legacy-prototype/) שתוכנן קודם לכן ב-Claude Design, ושומרת על אותה שפת עיצוב (מותג חותם: כחול `#0048FF`, גרדיאנט טורקיז→סגול, פונט Heebo, RTL).

## תכונות

- **הוספת חומרים** (`/admin`) — טופס אינטראקטיבי לעריכת כותרת/תקציר המליאה, והוספת חומרים (כותרת, קישור, קטגוריה, תיאור, קובץ מצורף אמיתי שנשמר בפועל בתיקיית `public/uploads`).
- **ייצוא PDF למחנכות** (`/export`) — מסמך מעוצב אחד (מליאה + כל החומרים עם קישורים חיים), עם כפתור "הדפסה / שמירה כ-PDF" (משתמש בדפדפן עצמו — `window.print()` — כך שהעברית מוצגת נכון והקישורים נשארים חיים ב-PDF שנוצר). זו דרך ההפצה המומלצת: אין צורך באחסון/אירוח ציבורי כלל.
- **תצוגת גלריה** (`/`) — כרטיס מליאה מרכזי מוקף בכרטיסי חומרים מחוברים בקווים מונפשים (דסקטופ), או רשימת אקורדיון (נייד/מסך צר), מגיבה אוטומטית לרוחב המסך. שימושי להרצה מקומית או הדגמה; אינה חלק חובה מתהליך העבודה.
- **קישורי שיתוף אמיתיים** (`/m/[slug]`) — לכל חומר יש גם עמוד נחיתה ייחודי משלו עם תמונת Open Graph שנוצרת אוטומטית, לשימוש עתידי אם יוחלט לארח את האפליקציה אונליין (ראו "אירוח עתידי" למטה) — לא נדרש לתהליך העבודה השוטף.
- **נגישות** — outline נראה במעבר מקלדת (`:focus-visible`), `aria-label`/`role="group"` על אלמנטים מרכזיים, `prefers-reduced-motion` מכבה אנימציות.

## הרצה מקומית (דרך העבודה השוטפת)

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

האפליקציה תרוץ בכתובת http://localhost:3000. המנחה מזין/ה חומרים ב-`/admin`, ואז לוחצ/ת על "ייצוא PDF למחנכות" כדי לפתוח את `/export` ולשמור/להדפיס כ-PDF לשליחה ידנית.

הנתונים (מליאה + חומרים + קבצים שהועלו) נשמרים מקומית בקובץ `prisma/dev.db` ובתיקיית `public/uploads` — אין צורך בחיבור אינטרנט או בחשבון ענן כלשהו כדי לעבוד עם האפליקציה.

## משתני סביבה

ראו `.env.example`. `DATABASE_URL` מצביע כברירת מחדל לקובץ SQLite מקומי. `NEXT_PUBLIC_SITE_URL` רלוונטי רק אם בעתיד תוחלט אירוח מקוון (ראו למטה).

## אירוח עתידי (אופציונלי — לא נדרש כרגע)

האפליקציה כוללת כבר את כל התשתית להפוך לשירות מקוון ציבורי (עם קישורי שיתוף אמיתיים לכל חומר, `/m/[slug]`), אם וכאשר ירצו בכך:

1. להחליף את `DATABASE_URL` במסד נתונים מנוהל (Postgres — למשל Neon, Supabase או Vercel Postgres) ולעדכן את `provider` ב-`prisma/schema.prisma` בהתאם.
2. להעביר את אחסון הקבצים המועלים משמירה מקומית (`public/uploads`) לאחסון אובייקטים (Vercel Blob, S3 וכד׳), כיוון שסביבות serverless לא שומרות קבצים בין הפעלות.
3. לחבר את הריפו ל-Vercel (או שירות דומה) לפריסה אוטומטית בכל push.

הפרויקט מקושר כבר לפרויקט Vercel בשם `hotam-facilitator-platform` (עם GitHub integration פעיל) ול-Blob store בשם `hotam-materials`, אך שלב חיבור מסד הנתונים המנוהל טרם הושלם — זהו הצעד היחיד שנותר במידה שיוחלט להמשיך בכיוון הזה.

## מבנה הפרויקט

- `src/app` — עמודי Next.js (App Router) ונקודות ה-API.
- `src/app/export` — עמוד ה-PDF/הדפסה.
- `src/components` — רכיבי React משותפים (Header, MaterialIcon, תצוגת הגלריה, טופס הניהול, כפתור ההדפסה).
- `prisma/schema.prisma` — מודל הנתונים (מליאה + חומרים).
- `legacy-prototype/` — הפרוטוטיפ הסטטי המקורי (Claude Design), נשמר להשוואה/היסטוריה בלבד — אינו חלק מהאפליקציה הרצה.
